# Паспорта объектов

Каталог квартир: навигация, доступ, парковка, характеристики, удобства, провайдер, свои строки и документы по каждому объекту.

Сайт — `index.html` на GitHub Pages. Данные лежат в репозитории:

| Файл | Что внутри |
|---|---|
| `data/objects.json` | Все объекты. Секретные поля зашифрованы в поле `enc`. |
| `data/fields.json` | Строки, добавленные «ко всем объектам», — шаблон для новых квартир. |
| `data/crypto.json` | Соль и проверочная строка для пароля (сам пароль здесь не хранится). |
| `files/<id объекта>/` | Фото и документы объекта. |
| `tools/passport.py` | Шифрование и расшифровка секретных полей. |

## Что зашифровано

Доступ в парадную (коды домофонов, тамбуров, кейбоксов), пароль Wi-Fi, лицевой счёт / логин провайдера и свои строки с пометкой `"secret": true`. Шифр AES-256-GCM, ключ из пароля через PBKDF2-SHA256 (600 000 итераций). На сайте коды открываются кнопкой «Показать коды» после ввода пароля.

## Как вносятся правки

Правки делаются через чат с Claude: «Довлатов: площадь 42 м², есть кондиционер», «добавь строку "Умный замок" ко всем объектам», «удали строку "Калитка" у Зевса». Claude меняет данные, шифрует секреты и отправляет коммит — сайт обновляется примерно через минуту.

Вручную:

```bash
export PASSPORT_KEY='пароль'
python3 tools/passport.py open   # расшифровать в .secrets/objects.plain.json (не попадает в git)
# правка .secrets/objects.plain.json
python3 tools/passport.py seal   # зашифровать обратно в data/objects.json
```

Смена пароля: `open` со старым паролем, затем `init` и `seal` с новым.
